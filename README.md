# Negombo Bliss - Tourism Website

A premium tourism website for Negombo, Sri Lanka, built with HTML, CSS (Tailwind via CDN), and JavaScript.

## How to Run
Simply open `index.html` in your web browser. No installation or server required.

## Features
- **Responsive Design**: Looks great on mobile and desktop.
- **Modern UI**: Uses glassmorphism, smooth transitions, and a premium color palette.
- **Sections**:
  - **Home**: Hero banner, introduction, and highlights.
  - **Attractions**: Detailed grid of top spots like the Beach, Lagoon, and Fort.
  - **Activities**: Card-based list of things to do (Diving, Boat Rides, etc.).
  - **Gallery**: A masonry-style photo gallery.
  - **Contact**: A modern contact form with an embedded map.

## Technologies
- HTML5
- Tailwind CSS (CDN)
- Vanilla JavaScript
- Google Fonts (Outfit, Playfair Display)
- Unsplash Images (High-quality placeholders)
